# Build Your Local AI Agent

An educational guide that explains how to build and run local AI agents on personal hardware.

This project was created to provide a research driven introduction to modern AI agent ecosystems, combining practical deployment guidance with concepts drawn from academic literature, university resources, official documentation, and industry best practices.

The guide covers:

- Hardware and memory requirements
- Local AI runtimes such as Ollama and LM Studio
- Language model selection and comparison
- The AI agent loop and agent architectures
- Tool calling, memory, and Retrieval Augmented Generation (RAG)
- Hermes Agent and Goose setup paths
- Security, permissions, sandboxing, and Docker isolation

Rather than focusing only on installation steps, the guide aims to help readers understand how local AI systems work, why specific design choices matter, and how to build safer and more effective agent workflows.

The website is fully static and organized into separate HTML, CSS, JavaScript, and asset files for maintainability and future expansion.

## Audience

This guide is intended for:

- Students
- Researchers
- Developers
- Technical professionals
- AI enthusiasts interested in local and private AI deployments

## Research Foundation

The content is based on peer reviewed research papers, university resources, official project documentation, model cards, and technical references from leading organizations in the AI ecosystem.
